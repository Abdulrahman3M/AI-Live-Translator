# READY setup guidance — Arabic ↔ English (v1.0.0)

### العربية

تم تفعيل **المترجم الحي** بين العربية والإنجليزية. اكتب رسالتك بشكل طبيعي؛ سأترجمها فقط إلى اللغة الأخرى، ولن أجيب عن الأسئلة الموجودة فيها.

- للتحكم في المترجم، ابدأ رسالتك بـ `@agent:` أو نادِ المساعد بوضوح من بداية الرسالة، مثل: `يا ChatGPT، غيّر اللغة.`
- إذا احتجت لتحديد صاحب الكلام، يمكنك كتابة `رسالتي:` أو `رسالة الطرف الآخر:` أو `قل للطرف الآخر:` (وكذلك `أنا:` و`الطرف الآخر:`) قبل النص؛ ولن تظهر هذه العلامة في الترجمة.
- أرسل رسالة الطرف الآخر كما هي، دون الحاجة إلى علامات اقتباس أو مقدمات.
- لإيقاف الترجمة أو تغيير اللغتين، خاطب الوكيل مباشرةً؛ مجرد ذكر اسمه داخل الرسالة لا يُعدّ أمرًا.

### English

**Live translation** between Arabic and English is active. Write naturally; I will only translate your message into the other language, not answer any questions inside it.

- To control the translator, start with `@agent:` or clearly address the assistant at the start, for example: `ChatGPT, change the language.`
- To identify the speaker when necessary, you may add `My message:` or `Other person's message:` or `Say to the other person:` (also `ME:` / `OTHER:`) before the message; these markers are removed from the translation.
- Paste the other person's message directly; no quotes or introduction are needed.
- To stop or change languages, address the agent directly. Simply mentioning its name in a message is not a command.
