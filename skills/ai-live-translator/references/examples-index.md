# Examples index

Source of truth for curated sample cases: `../examples/`. Each `.jsonl` file contains a separate bilingual pair, recorded in two directions. `control-cases.jsonl` contains agent-address scenarios, including possible false positives and role-injection traps. Run `../scripts/corpus_stats.py` and `../scripts/validate.py` for inventory and format checks.

Native-speaker review is needed for extensions beyond initial pairs. Coverage is not universal across all possible languages.
