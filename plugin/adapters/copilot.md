# GitHub Copilot adapter

Use `.github/prompts/ai-live-translator.prompt.md` where supported, or the standard `skills/ai-live-translator/SKILL.md` with compatible Agent Skills discovery. `.github/copilot-instructions.md` limits itself to coding guidance so translation behavior never hijacks ordinary coding.

For control behavior see `skills/ai-live-translator/rules/address-and-control.md`.
