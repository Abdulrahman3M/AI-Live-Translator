# Agent adapter index

**AI Live Translator** — Translate messages both ways.

For a short platform comparison, see [`docs/installation.md`](../../docs/installation.md) or its [Arabic version](../../docs/installation.ar.md).

- `generic-agent.md`: universal prompt-only fallback.
- `claude-code.md`: native plugin manifest and commands.
- `codex.md`: Agent Skills and explicit skill loading.
- `copilot.md`: Copilot prompt files and skills support.
- `gemini.md`: manual prompt/skill activation.
- `chatgpt.md`: manual Custom Instructions / compatible chat instruction mechanism.

Adapters are **installation instructions**, not claims of identical host support. The canonical runtime contract is in `skills/ai-live-translator/SKILL.md`.
