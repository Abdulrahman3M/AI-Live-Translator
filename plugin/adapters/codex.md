# OpenAI Codex adapter

Install `skills/ai-live-translator/` in a Codex-recognized skills folder and explicitly activate the skill (for example `$ai-live-translator` where supported). `AGENTS.md` governs repository editing; it is not a global translation request. Manual prompt insertion is a fallback.

For control behavior see `skills/ai-live-translator/rules/address-and-control.md`.
