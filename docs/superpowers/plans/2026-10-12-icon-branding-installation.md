# Icon, Branding, and Installation Polish Implementation Plan

> **For agentic workers:** Execute this plan task-by-task with `superpowers:executing-plans`.

**Goal:** Ship the selected two-bubble translation-loop identity with consistent manifests, distribution assets, concise installation guidance, and richer regression fixtures.

**Architecture:** Keep the icon as repository-native SVG and export PNG sizes for supported hosts. OpenAI plugin manifests point to root `assets/`; Agent Skill metadata points to matching 64 px and 512 px copies in that skill's `assets/`; Claude Code keeps its supported manifest shape. English and Arabic installation summaries live under `docs/`, while the complete instructions remain under `plugin/installation/`.

**Tech Stack:** JSON, Markdown, SVG, PNG, Python standard library, Node.js `sharp`, Git.

**Spec:** User-approved request and selected loop icon in the conversation on 2026-10-12.

## Global Constraints

- Use release version `1.0.6` consistently across `VERSION`, manifests, README titles, prompts, and `CHANGELOG.md`.
- Keep the portable Agent Plugins root manifest closed to its supported fields; place icon metadata under supported OpenAI extensions.
- Preserve three primary functional directories: `prompt/`, `skills/`, and `plugin/`.
- Keep the ChatGPT ZIP minimal and generated by `plugin/installation/build-chatgpt.py`.
- Keep runtime behavior local and text-only; do not add network calls, storage, or telemetry.

## Review Focus

- Small icon sizes must retain clear arrows and speech bubbles: verify generated dimensions and inspect the SVG rendering.
- Every manifest asset path must resolve inside the plugin ZIP: verify paths from manifests against archive members.
- Added bilingual pairs must preserve names, dates, times, dialect tone, and their reverse records: verify fixture content and corpus symmetry.
- Clarification fixtures must not be counted as translation records: verify the offline validator and corpus statistics.
- All public install surfaces must use the canonical product label and short description: compare manifests and installation entry points.
