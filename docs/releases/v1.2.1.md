# AI Live Translator v1.2.1

This pre-release is intended for evaluation before promotion to a stable release. AI Live Translator provides bidirectional, text-only interpretation of ordinary messages and a separate subtitle workflow. The selected model affects tone, context and dialect quality; session controls require explicitly addressing the agent.

## Changes

- Continue subtitle translation in ordered batches and track resumable progress when supported.
- Account for all source events before declaring completion and report specific blockers and partial work accurately.
- Use an available goal mechanism when host rules and user authorization permit; apply the same completion contract otherwise.
- Preserve the source and disclose uncertainty and whether visual rendering was checked.

Translation quality and adherence depend on the host and model. Structural checks cannot prove semantic accuracy. Review subtitles and render them in the intended player. The portable Agent Skill package contains the live interpreter; the host plugins and source package include the subtitle workflow.
