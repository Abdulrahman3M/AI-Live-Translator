# AI Live Translator v1.1.2

## Summary

AI Live Translator provides a bidirectional, text-only interpreter for ordinary messages and a separate subtitle workflow. It preserves tone, context, and dialect according to the selected model and language pair. Session controls require explicitly addressing the agent. This v1.1.2 release reissues the package set and updates the homepage hero artwork to the approved planet-and-conversation design. The artwork uses the established blue and gold palette and contains no generated text, so the page copy remains accessible and typeset by GitHub.

## Included capabilities

- Bidirectional text translation and the separate subtitle translation workflow.
- Reference-driven ASS styling, offline assembly helpers, and resumable subtitle checkpoints.
- Updated English and Arabic installation links and project documentation.
