# AI Live Translator v1.0.8

AI Live Translator now offers two workflows: live bidirectional translation for ordinary messages and SRT/ASS subtitle translation. Preserve the text-only contract, tone, context, dialect, and explicit agent controls by explicitly addressing the agent when issuing a command. Translation quality varies by model and language pair. The subtitle workflow translates subtitle events into a styled ASS file while preserving event order and timing, with optional speaker colors and RTL-aware formatting.

## Highlights

- Added a dedicated subtitle translation skill for SRT and ASS input, with target language, dialect/register, and optional styling choices.
- Converts event timing to ASS centiseconds, preserves overlaps and ordering, and reports source events that cannot be recovered.
- Added ASS and right-to-left formatting guidance, along with integration coverage for workflow routing and subtitle package contents.
- Added host-aware voice-turn guidance for interim transcripts, intentional speech detection, translation direction, and best-effort completion of current output.
- Added worked voice scenarios, structured fixtures, and bilingual ChatGPT Advanced Voice usage guidance.
- Preserved the text-only, bidirectional translation contract and explicit agent controls for ordinary messages.

## Platform limits

Voice-turn guidance applies only to text and transcript context provided by the host. The plugin cannot control microphone access, raw audio, noise reduction, speaker identification, silence thresholds, or voice playback interruptions. Translation quality depends on the selected model and language pair.
