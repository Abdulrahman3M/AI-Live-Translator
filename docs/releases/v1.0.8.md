# AI Live Translator v1.0.8

## English

**AI Live Translator — Translate messages both ways.** This patch improves best-effort handling of voice-derived transcripts while preserving the existing text-only, bidirectional translation contract for ordinary messages.

- Added **Voice Turn Management** with **Semantic End-of-Turn Detection** guidance for interim speech: a brief pause does not necessarily finish a thought, while finalized chat messages remain immediately translatable.
- Added **Uninterrupted Translation Mode** guidance to prioritize finishing a current translation once without voluntarily switching to unrelated background speech.
- Added a three-stage intended-speech, language identification, and translation-direction check; preserves short utterances, tone, context, dialect, names, and negation.
- Added twelve regression scenarios and mirrored limitations in English and Arabic ChatGPT guides.
- Existing controls still require explicitly addressing the agent; ordinary messages receive only their translation.

**Platform limits:** These are instructions for processing host-supplied text, not raw audio controls. AI Live Translator cannot change ChatGPT Advanced Voice silence thresholds, disable interruptions, suppress microphone noise, identify the physical speaker, or guarantee noninterruptible playback. Results depend on the selected model and host. No dedicated audio application is included.
