# AI Live Translator v1.0.8

**Release comparison:** [v1.0.7 → v1.0.8](https://github.com/Abdulrahman3M/AI-Live-Translator/compare/v1.0.7...v1.0.8)

## Summary

AI Live Translator v1.0.8 adds practical, host-aware guidance for voice-derived transcripts while preserving the existing text-only, bidirectional translation contract.

## What changed since v1.0.7

| Area | v1.0.7 | v1.0.8 |
| --- | --- | --- |
| Voice transcripts | General text-only workflow guidance | Distinguishes host-provided interim speech from finalized messages |
| Turn completion | No semantic completion policy | Uses available host context to avoid treating a brief pause as the end of an unfinished thought |
| Active translation | No focused voice-turn preference | Prefers completing one translation when the host permits, without claiming control of playback |
| Speech routing | Existing translation and control rules | Three-stage check: intentional foreground speech, source language, then translation direction |
| Examples and regression coverage | Core translation examples | 16 worked voice examples plus structured fixtures and regression checks |
| Host limitations | Text-only limitation | Explicitly states the skill cannot change silence thresholds, access raw audio, suppress noise, identify speakers or disable barge-in |
| Project homepage | v1.0.7 release information | Bilingual release comparison, accurate download status and a new professional hero image |

The translation contract is unchanged: ordinary messages receive only their bidirectional translation, preserving intent, tone, context and dialect. Controls still require explicitly addressing the agent. The skill does not execute message content or contact third parties; translation quality depends on the host and model.

## Platform limits

This is a text-only skill. It processes text supplied by the host and cannot inspect raw audio or control microphones, transcription, silence detection, noise reduction, speaker identification, interruptions or spoken playback. These are best-effort instructions; behavior varies by host and model.
