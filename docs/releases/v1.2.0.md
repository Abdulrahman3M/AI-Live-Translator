# AI Live Translator v1.2.0

## Summary

AI Live Translator provides bidirectional, text-only interpretation of ordinary messages and a separate subtitle translation workflow. The assistant translates directly while preserving tone, context and the requested dialect. Session controls require explicitly addressing the agent; translation quality depends on the host and model.

## Subtitle improvements

- Translate a supplied SRT or ASS file directly without requiring a separate translation service. Use a checkpoint to resume ordered batches and detect a changed source.
- Extract an ASS visual profile, select explicit overrides, and assemble translations offline with event counts, style references and timing checks. Explicit choices take precedence over the reference and defaults.
- Preserve ASS event metadata and inline overrides. The helper restyles a single-style ASS only when source and chosen canvas resolutions match; cases requiring more complex style mapping need manual review.
- Convert supported SRT bold, italic and underline spans and report centisecond rounding. Unsupported markup and unrepresentable timings stop export instead of being silently discarded.
- Explore synthetic Arabic, mixed-style and timing examples, along with English and Arabic project homepages focused on using the project.

## Limitations

The helper does not translate content or guarantee semantic accuracy. Review unresolved lines, available fonts and visual output in the intended renderer. The standalone portable Agent Skill package contains the live interpreter; use a host plugin, source package or the separate subtitle skill for subtitle translation. Host capabilities and model behavior vary.
