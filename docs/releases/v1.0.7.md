# AI Live Translator v1.0.7

## English

**AI Live Translator — Translate messages both ways.** Turn a compatible AI agent into a text-only interpreter for a selected language pair.

- Provide bidirectional text translation; ordinary messages receive only their translation, without an answer to their content.
- Preserve intent, tone, context, dialect, names, numbers, dates, and formatting.
- Handle mixed-language messages and ask for clarification when ambiguity could change the meaning.
- Control the session by explicitly addressing the agent directly or using `@agent:`.
- Install through packages for ChatGPT, Codex, or Claude Code, or use the portable Agent Skill with compatible hosts. A source-code ZIP is also included.

Translation quality and plugin support depend on the chosen model and host. The tool processes text supplied by the host; it does not listen to microphones or translate calls or raw audio.

## العربية

**AI Live Translator — ترجمة الرسائل ذهابًا وإيابًا.** حوّل وكيل ذكاء اصطناعي متوافقًا إلى مترجم نصي لزوج اللغات الذي تختاره.

- يوفّر ترجمة نصية ذهابًا وإيابًا؛ وتحصل الرسائل العادية على ترجمتها فقط دون الإجابة عن محتواها.
- يحافظ على المقصد والنبرة والسياق واللهجة والأسماء والأرقام والتواريخ والتنسيق.
- يتعامل مع الرسائل المختلطة اللغات، ويطلب التوضيح عندما قد يغيّر الالتباس المعنى.
- تحكّم في الجلسة بمخاطبة الوكيل مباشرة أو باستخدام `@agent:`.
- ثبّته عبر حزمة ChatGPT أو Codex أو Claude Code، أو استخدم Agent Skill المحمولة مع المضيفين المتوافقين. تتوفر أيضًا حزمة ZIP للمصدر.

تعتمد دقة الترجمة ودعم الإضافة على النموذج والمضيف. تعالج الأداة النص الذي يوفّره المضيف؛ ولا تستمع إلى الميكروفون ولا تترجم المكالمات أو الصوت الخام.
