# أدلة إعداد المترجم لوكلاء الذكاء الاصطناعي

اختر الدليل الخاص بالمنصة التي تريد تشغيل **AI Live Translator** عليها.

**ترجمة الرسائل ذهابًا وإيابًا.**

لمقارنة المنصات بسرعة، ابدأ بـ[دليل التثبيت المختصر](../installation.ar.md)، ثم افتح الدليل التفصيلي للمنصة.

| الوكيل | الدليل | المسار المقترح |
|---|---|---|
| ChatGPT | [إعداد ChatGPT](CHATGPT.ar.md) | أنشئ حزمة ChatGPT المخصصة ثم ارفعها |
| Claude | [إعداد Claude](CLAUDE.ar.md) | ارفع إضافة Claude إلى Claude.ai أو حمّل مجلد المشروع في Claude Code |

توضح الأدلة الفرق بين ملفات المصدر الكاملة على GitHub والملفات الخاصة التي يحتاجها كل وكيل. ملف **Download ZIP** التلقائي من GitHub هو أرشيف ملفات المصدر، وليس حزمة ChatGPT الجاهزة للرفع.

## السلوك والحدود المشتركة

AI Live Translator عبارة عن تعليمات ومهارات، وليس نموذج ترجمة مستقلًا أو خدمة ميكروفون. النموذج الذي تختاره هو الذي يفسر النص الذي يستقبله؛ لذلك قد تختلف جودة الترجمة ودعم أزواج اللغات والالتزام بالترجمة فقط بحسب النموذج واللغة والجلسة. عند استخدام الصوت، ميّز رسالتك عن كلام الطرف الآخر بوضوح؛ فالأداة لا تفحص الصوت الخام ولا تفصل المتحدثين بنفسها.

لأفضل إعداد أولي موصى به في المشروع، استخدم ChatGPT Voice مع **Model → Advanced**. هذه التوصية مبنية على تجارب مالك المشروع المكثفة، ولا تضمن أن بقية الوكلاء لن تعمل.
