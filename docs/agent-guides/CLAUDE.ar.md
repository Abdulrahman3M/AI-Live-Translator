# استخدام AI Live Translator مع Claude

توجد أكثر من طريقة لاستخدام إضافات Claude. يشرح هذا الدليل رفع الإضافة في **Claude.ai / Claude Desktop / Cowork**، وتشغيلها محليًا في **Claude Code**. يمكن استخدام ملفات المشروع الكاملة مصدرًا، لكن يجب اختيار مجلد الإضافة الصحيح والحفاظ على بنية الملفات.

## ما الملفات المطلوبة؟

احتفظ بالمسارات التالية معًا داخل جذر واحد للإضافة:

- `.claude-plugin/plugin.json` — ملف تعريف إضافة Claude ومسارات الأوامر.
- `plugin/commands/` — ملفات Markdown التي يشير إليها ملف التعريف.
- `skills/` — مهارتا الترجمة والإعداد وكل ملفات المراجع والأمثلة والسكربتات والموارد التابعة لهما.
- `prompt/live-translation.md` — اختياري، كخطة بديلة لاستخدام التعليمات يدويًا بدلًا من تثبيت الإضافة.

أبسط طريقة آمنة هي إبقاء مجلد المستودع كاملًا كما هو واستخدام مجلده الرئيسي جذرًا للإضافة. أدوات Python والاختبارات وملف `plugin.json` الخاص بـChatGPT وملفات CI ليست مطلوبة لتشغيل Claude. إذا أنشأت مجلدًا أصغر أو ZIP، فحافظ على المسارات المذكورة كما هي؛ لأن ملف التعريف يشير إلى مسارات داخل جذر الإضافة.

## Claude.ai وClaude Desktop وCowork: رفع الإضافة

1. نزّل المستودع وفك ضغطه، أو جهّز مجلدًا يحتوي على المسارات المطلوبة أعلاه.
2. تحقق أن جذر الإضافة يحتوي على `.claude-plugin/plugin.json` وأن مجلدي `plugin/commands/` و`skills/` بجوار مجلد `.claude-plugin/`.
3. إذا استخدمت ZIP، فاضغط جذر الإضافة أو محتوياته بحيث يحتوي الأرشيف على ملف واحد فقط `.claude-plugin/plugin.json` في جذر الإضافة. لا ترفع ZIP التلقائي من GitHub دون التحقق من طبقة المجلدات داخله.
4. في Claude افتح **Customize → Plugins → Add → Upload plugin**.
5. اختر مجلد الإضافة أو ملف `.zip` أو `.plugin` وفق ما تقبله نافذة الرفع. راجع تفاصيل الإضافة ثم أضفها.
6. في محادثة جديدة اكتب `/` للعثور على المهارة أو الأمر، أو استدعِ أمر البدء المتاح. يتضمن المشروع الأمر `/ai-live-translator:start` في Claude Code؛ وقد يختلف ظهور الأوامر وأسماؤها بين واجهات Claude.
7. اتبع أسئلة الإعداد لاختيار اللغتين ثم اختبرها بجملة قصيرة واحدة.

بعد الرفع على مستوى الحساب، قد تكون الإضافة متاحة في Claude chat وCowork وClaude Code عند استخدام الحساب نفسه، وفق المكونات التي تدعمها كل واجهة. قد تختلف خيارات الرفع وصلاحيات المؤسسة.

## Claude Code: تحميل المستودع المحلي

1. ثبّت Claude Code ونزّل/فك ضغط المستودع أو انسخه باستخدام Git.
2. افتح طرفية في مجلد العمل الذي تريده.
3. مرّر **المسار الكامل للمجلد الرئيسي للمستودع** (المجلد الذي يحتوي على `.claude-plugin/`) إلى Claude Code:

```bash
claude --plugin-dir "/absolute/path/to/AI-Live-Translator"
```

مثال على macOS/Linux إذا فككت الملفات داخل Downloads:

```bash
claude --plugin-dir "$HOME/Downloads/AI-Live-Translator"
```

4. في جلسة Claude Code التي تبدأ، نفّذ `/ai-live-translator:start` للبدء، أو `/ai-live-translator:help` لعرض المساعدة.
5. إذا لم يظهر أمر أو Skill، شغّل `claude plugin validate "/absolute/path/to/AI-Live-Translator"`، وتحقق أنك استخدمت مجلد المستودع الرئيسي ولم تنقل ملف التعريف أو ملفات الأوامر.
6. طريقة `--plugin-dir` تحمّل الإضافة لهذه الجلسة. أعد تشغيل Claude Code مع الخيار في الجلسات التالية. أما التثبيت من Marketplace أو من إضافة متزامنة مع الحساب فيُحدّث من خلال مصدر التثبيت نفسه.

لتحميل نسخة محلية أحدث، حدّث ملفات مجلد المستودع ثم أعد تشغيل Claude Code باستخدام `--plugin-dir` (أو نفّذ `/reload-plugins` بعد تعديل الملفات في جلسة نشطة). تُدار إضافات Claude المرفوعة على الحساب من **Customize → Plugins**، ويعتمد التحديث على مصدرها؛ وقد تحتاج النسخة المرفوعة يدويًا إلى رفع/استبدال أرشيفها الجديد.

## بديل يدوي باستخدام prompt فقط

إذا كانت واجهة Claude التي تستخدمها لا توفر رفع الإضافات، انسخ كامل محتويات `prompt/live-translation.md` إلى تعليمات المشروع أو المحادثة التي تدعمها الواجهة، ثم فعّل المترجم صراحةً. هذا استخدام عبر prompt وليس إضافة مثبتة، وتختلف استمرارية التعليمات بين واجهات Claude.

## وضوح الصوت وجودة الترجمة

افصل بوضوح بين الكلام الموجّه إلى الذكاء الاصطناعي وكلام الطرف الآخر والأصوات الجانبية. استخدم تسميات مثل **«رسالتي:»** و**«رسالة الطرف الآخر:»**، وتحدث بالتناوب وتجنب التحدث فوق التلفاز أو المحادثات القريبة. تستقبل المهارة النص الذي يقدمه Claude؛ ولا تعالج صوت الميكروفون الخام أو تحدد هوية المتحدث. إذا احتوى التفريغ على تداخل أو ضوضاء أو كان المتحدث غير واضح، اطلب إعادة الجملة بوضوح أو كتابتها أو تحديد المتحدث بدل التخمين.

يحتوي AI Live Translator على تعليمات ومهارات، وليس نموذج ترجمة مستقلًا. جُرّب المشروع بشكل مكثف مع ChatGPT أكثر من غيره، لذلك فهو نقطة البداية المقترحة. يمكن تجربة Claude والوكلاء المتوافقين الآخرين، لكن الدقة والالتزام قد يختلفان حسب نموذج الذكاء الاصطناعي وزوج اللغات والجلسة.
